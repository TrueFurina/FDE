## 一、需求拆解总览

### 1.1 需求分层

| 层级 | 定义 | 包含内容 |
|------|------|---------|
| **P0 核心闭环** | 系统跑通必需 | 知识库、RAG检索、意图识别、答案生成、合规风控 |

## 二、需求优先级矩阵

### 2.1 按价值/成本/风险评分

| 需求 | 业务价值 | 实现成本 | 技术风险 | 优先级 |
|------|---------|---------|---------|--------|
| RAG知识检索 | ★★★★★ | 低 | 低 | **P0** |
| 意图识别路由 | ★★★★ | 低 | 低 | **P0** |
| 合规风控 | ★★★★★ | 低 | 低 | **P0** |
| 答案生成+来源 | ★★★★★ | 低 | 中 | **P0** |
| 转人工机制 | ★★★★★ | 低 | 低 | **P0** |
| Grounding护栏 | ★★★★ | 低 | 中 | **P1** |
| 查询重写重试 | ★★★ | 低 | 中 | **P1** |
| 多轮对话 | ★★★ | 中 | 中 | P2 |
| 知识图谱 | ★★★★ | 高 | 高 | P2 |
| MCP接入 | ★★★ | 中 | 中 | P2 |

### 2.2 决策依据

- **P0 必须做**：影响核心闭环，不做系统无法运行
- **P1 应该做**：提升可靠性，缺了质量不达标
- **P2 可以做**：扩展能力，时间允许再投入

## 五、依赖关系图

```
数据文档(A) → 分块(A2) → 向量化(A3) → 检索引擎(B) → 意图路由(C1)
                                        ↓                ↓
                                      RRF融合(B3)     答案生成(C3)
                                        ↓                ↓
                                    查询重写(B4)      Grounding(D2)
                                                        ↓
                                                    合规风控(D1)
                                                        ↓
                                                    Web界面(E1)
```

### 关键依赖说明

1. **A → B**：检索依赖数据索引，先建库再检索
2. **B → C**：生成依赖检索结果，先检索后生成
3. **C → D**：风控检查生成结果，先生成后校验
4. **全部 → F**：测试覆盖全部模块，最后验证
