## 一、项目概述

### 1.1 项目背景

美妆零售企业拥有多个品牌/品类的商品线，客服与导购每日需处理大量客户咨询（产品选择、成分功效、适用肤质、使用方法、库存效期、退换货、不良反应等）。当前存在以下核心问题：

- **知识分散**：商品资料、服务规范分散在多份文档，版本不一致
- **效率低下**：客服人工查找信息平均耗时 5-15 分钟
- **风险失控**：功效描述易越界（广告法风险）、高风险问题（过敏/不良反应）依赖人工判断
- **经验难复制**：资深员工经验在个人脑中，新人需 2-4 周培训才能独立上岗

### 1.2 项目目标

构建一套**美妆零售 AI 知识库与客服辅助系统**，实现：

| 目标 | 量化指标 |
|------|---------|
| 客服响应提速 | 从 5-15 分钟缩短至 < 1 分钟 |
| 回答口径统一 | 一致性从 ~60% 提升至 ≥ 90% |
| 合规风险可控 | 越界/医疗/绝对承诺检出率 100% |
| 新人快速上岗 | 培训周期从 2-4 周缩短至 ≤ 1 周 |
| 知识可审计 | 每条回答标注知识来源 |

### 1.3 项目价值

- 直接价值：客服效率提升 90%+，合规风险从"不可控"变为"100% 可控"
- 间接价值：品牌形象统一、知识资产沉淀、客户信任提升

## 二、项目范围

### 2.1 范围内（In Scope）

| # | 工作项 | 说明 |
|---|--------|------|
| 1 | 知识库建设 | 4 篇知识文档（产品/成分/用法/售后）+ 向量化索引 |
| 2 | RAG 检索系统 | FAISS 向量 + BM25 关键词 + RRF 融合 |
| 3 | 意图识别路由 | 6 类意图分类 + 高风险自动转人工 |
| 4 | 答案生成 | DeepSeek LLM + 知识来源标注 |
| 5 | 合规风控 | 医疗诊断/绝对承诺/功效越界/医疗暗示检测 |
| 6 | Grounding 护栏 | LLM 校验回答是否基于资料（防幻觉） |
| 7 | 查询重写重试 | 检索失败自动改写查询重试 |
| 8 | Web 演示界面 | Streamlit 交互界面 |
| 9 | 测试验证 | 30 项测试集 + 评估报告 |

### 2.2 范围外（Out of Scope）—— 6 项不做什么

| # | 不做项 | 说明 |
|---|--------|------|
| 1 | 不接入真实 IM 系统 | 仅 Web 演示/API，不对接企业微信/飞书 IM |
| 2 | 不构建多轮对话 | 单轮问答优先 |
| 3 | 不构建知识图谱 | 仅文档检索 |
| 4 | 不处理多模态输入 | 仅文本问答 |
| 5 | 不修改原始知识文档 | 知识只读 |
| 6 | 不做用户权限管理 | 无登录/角色/权限 |

## 七、项目假设与约束

### 7.1 假设

1. 模拟数据包覆盖核心问答场景
2. DeepSeek API 可用且响应 ≤ 5s
3. 本地环境可完整运行系统
4. 测试集由交付方设计，客户确认

### 7.2 约束

1. 使用课程提供的脱敏模拟数据，不涉及真实客户隐私
2. 不得自动修改原始知识文档
3. 系统不替代财务/医疗等专业判断
4. 交付时间受 FDE 共学营课程周期约束
