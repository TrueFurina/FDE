### 3.3 优化记录

**第一轮优化（86.7% → 96.7%）：**

**优化1：意图识别**
- 新增"强使用词"优先级（怎么用/如何使用/用量/涂抹等优先判定为 usage）
- 扩充成分关键词库（玻色因/传明酸/熊果苷/虾青素等 15+ 新词）
- 修复：N03 视黄醇怎么用 → usage；B04 玻色因 → ingredient

**优化2：RAG 检索分词**
- 中文分词从"1-3字贪婪匹配"改为"单字+2-gram+3-gram 组合"
- 修复：短词"面霜"可正确匹配（原被切为"面霜多"/"控油面"）

**第二轮优化（参考 GitHub 同类项目创新点）：**

**优化3：查询重写+重试**（借鉴 Langgraph Multi-Agent）
- 检索质量低时（rrf < 阈值）自动用 LLM 重写查询后重试
- 合并两轮结果去重，标注 via_rewrite
- 修复短查询召回不足问题

**优化4：标题感知分块**（借鉴 octavian115）
- 从纯字符分块改为按 Markdown 标题切分（40 块，原 20 块）
- 每个文本块带标题路径上下文（如"产品目录 > 品牌与产品线 > 洁面系列"）
- 表格不再被切断，检索精准度提升

**优化5：Grounding 护栏**（借鉴 Langgraph Multi-Agent）
- LLM 校验回答是否基于检索资料，检测幻觉
- 输出 grounded/partial/hallucinated + 置信度 + 幻觉内容列表
- 验证：回答置信度 0.95-1.0，无幻觉

### 3.4 剩余失败项（后续优化方向）

| 用例 | 问题 | 原因 | 优化建议 |
|------|------|------|---------|
| RAG 烟酰胺（纯短查询） | 未召回成分文档 | 短查询向量偏向产品目录 | 增加查询扩展/语义消歧 |

## 四、Skill 交付（合规风控检查）

### 4.1 Skill 定义

| 属性 | 内容 |
|------|------|
| 名称 | compliance-check |
| 功能 | 美妆客服回答合规风控检查 |
| 输入 | 待检查文本 |
| 输出 | {verdict, reason, violated_rules} |
| 判决级别 | pass（通过）/ block（拦截）/ human（转人工）|

### 4.2 规则库

| 规则 | 关键词示例 | 级别 |
|------|-----------|------|
| 医疗诊断 | 治疗/治愈/处方/疗程 | block |
| 绝对承诺 | 100%/绝对/保证 | block |
| 功效越界 | 美白/抗衰老/祛斑 | human |
| 医疗暗示 | 医院/医生推荐/疗效 | human |

### 4.3 测试结果（7/7 通过）

| 测试 | 判决 | 说明 |
|------|------|------|
| 正常回答 | pass ✅ | 未触发规则 |
| 含医疗词 | block ✅ | "治疗"触发医疗诊断 |
| 绝对承诺 | block ✅ | "绝对"+"100%"触发 |
| 功效越界 | human ✅ | "美白"触发，需确认备案 |
| 医疗暗示 | human ✅ | "医院"触发 |
| 空文本 | pass ✅ | 无内容跳过 |
| 纯英文 | pass ✅ | 中文规则不触发 |
