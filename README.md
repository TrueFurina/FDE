# 美妆零售知识库与客服协作 · 大作业项目

## 目录结构
- data/     - 模拟数据（知识文档、向量索引）
- src/      - 源代码（RAG引擎、Agent、WebUI）
- skills/   - Skill 定义（合规风控等）
- tests/    - 测试集与测试脚本
- docs/     - 文档（需求清单、架构设计、报告）
- output/   - 输出（测试结果、交付物）
- scripts/  - 辅助脚本

## 技术栈
- Python 3.13 + FAISS + BM25 + RRF
- DeepSeek v4 flash (LLM)
- Streamlit (Web UI)
