# 产品使用方法指南

> 脱敏模拟数据，用于大作业开发测试

## 一、洁面产品使用方法

### 氨基酸温和洁面乳
- **使用步骤**：取适量于掌心，加水揉出泡沫，轻柔按摩面部30秒，温水洗净
- **使用频率**：早晚各一次
- **注意事项**：避免入眼；敏感肌适用

### 控油祛痘洁面啫喱
- **使用步骤**：取适量于掌心，加水揉出泡沫，重点按摩T区和痘痘部位
- **使用频率**：早晚各一次
- **注意事项**：含水杨酸，避免过度清洁；若皮肤干燥可减少至每晚一次

### 舒缓修护洁面泡沫
- **使用步骤**：按压出泡沫，直接涂抹面部，轻柔按摩后洗净
- **使用频率**：早晚各一次
- **注意事项**：适合干性、敏感性肌肤

## 二、精华产品使用方法

### 玻尿酸保湿精华
- **使用步骤**：洁面后取2-3滴于掌心，按压于面部至吸收
- **使用顺序**：水→精华→乳液/面霜
- **注意事项**：可在化妆水后使用，加强保湿效果

### 烟酰胺焕亮精华
- **使用步骤**：取2-3滴于掌心，均匀涂抹面部，避开眼周
- **使用频率**：建议从隔天一次开始，逐步过渡到每天一次
- **注意事项**：初次使用可能出现轻微刺痛，属建立耐受过程；如持续不适请停用

### 视黄醇抗皱精华
- **使用步骤**：仅晚间使用，取豌豆大小于面部涂抹
- **使用频率**：初期每周2-3次，逐步增加至每晚
- **注意事项**：白天必须使用防晒；孕期禁用；避免与高浓度酸类同时使用

## 三、面霜产品使用方法

### 神经酰胺修护面霜
- **使用步骤**：精华后取适量均匀涂抹，按摩至吸收
- **使用顺序**：水→精华→面霜
- **注意事项**：适合干性、敏感性肌肤，可在夜间厚涂作为睡眠面膜

### 水杨酸控油面霜
- **使用步骤**：精华后取适量涂抹T区及易出油部位
- **使用频率**：早晚各一次
- **注意事项**：含水杨酸，避免与视黄醇精华同时使用

### 胶原蛋白紧致面霜
- **使用步骤**：取适量于面部，配合提拉按摩手法使用
- **使用频率**：早晚各一次
- **注意事项**：适合成熟肌，配合按摩效果更佳

## 四、产品搭配建议

### 日常护肤流程（全套）
1. 洁面 → 2. 化妆水（如有）→ 3. 精华 → 4. 乳液/面霜 → 5. 防晒（白天）

### 早晚搭配方案
| 时段 | 方案A（清爽型） | 方案B（修护型） |
|------|---------------|---------------|
| 早 | 洁面 → 玻尿酸精华 → 水杨酸面霜 → 防晒 | 洁面 → 烟酰胺精华 → 修护面霜 → 防晒 |
| 晚 | 洁面 → 玻尿酸精华 → 控油面霜 | 洁面 → 视黄醇精华 → 神经酰胺修护面霜 |

### 新手入门建议
- 建议从温和产品开始，逐步建立耐受
- 敏感肌先做局部测试（耳后/下颌），确认无不适再全脸使用
- 新成分产品建议间隔2-4周逐一引入，便于判断反应
